## Key Features

- Dark & Light Mode – Automatically adapts to system theme.

- Website Shortcuts – Add shortcuts with app-like icons; automatically retrieves the highest-resolution favicon using an advanced scraping algorithm.

- Modern, Minimal Interface – Built with shadcn/ui for responsive components and consistent design.

## In Development

- Customizable UI – Adjust backgrounds, theme colors, and layout to match your workflow or style.

- Productivity widgets.

- Advanced shortcut management.

Transform your new tab into a personalized, minimal dashboard.
